# TF2 坐标变换（p08）

> 对应代码：`src/p08_tf2/`。ROS 1 的 tf1 在 ROS 2 彻底退场，只有 tf2。

## 1. TF 树概念（3 分钟复习）

- 每个 TF 是一条**父帧→子帧**的有向边，全部变换构成**一棵树**（可以有多个连通分量，但不能有环/多父）。
- 查询任意两帧：tf2 沿树自动取逆与复合，**不需要手动求逆**。
- 每个变换带时间戳；查询"未来"时刻会报**外推（extrapolation）**错误——p08 专门演示。
- 本包建立的树：

```
map ──(静态 1.0,0.5,0)──> odom ──(20Hz 前进+旋转)──> base_link ──(20Hz 摆动)──> sensor
```

## 2. 广播（C++）

```cpp
// 静态（走 /tf_static 话题，只发一次，新监听者也能收到）
tf2_ros::StaticTransformBroadcaster sb(this);
sb.sendTransform(tf);   // 可以周期性重发，内容不变即可

// 动态（走 /tf 话题）
tf2_ros::TransformBroadcaster db(this);
db.sendTransform(tf);   // 每个周期发当前值

// 构造变换：2D 姿态只需 setRPY(0,0,yaw)
tf2::Quaternion q; q.setRPY(0.0, 0.0, yaw);
tf.transform.rotation = tf2::toMsg(q);
```

> 实测注意：静态变换走 **/tf_static** 而非 /tf；`ros2 topic hz /tf` 看到的只是动态部分。
> 同一个子帧有两个父帧时 tf2 **静默忽略**后到的一条（不报错），排查时先 `view_frames` 看树。

## 3. 监听与查询（C++）

```cpp
tf2_ros::Buffer buffer(this->get_clock());   // 必须先声明 buffer
tf2_ros::TransformListener listener(buffer); // 再声明 listener（依赖 buffer）

// 查询"最新"变换：用 TimePointZero
auto t = buffer.lookupTransform("sensor", "map", tf2::TimePointZero);
// 反向查询（子→父）：tf2 自动取逆，无需手动 invert

// 点变换：把 map 系点变到 sensor 系
geometry_msgs::msg::PointStamped p;
p.header.frame_id = "map";
p.point.x = 1.0; ...
auto out = buffer.transform(p, "sensor");

// 查询"未来"（经典错误演示）：
buffer.lookupTransform("sensor", "map", this->now() + 10s);
// → 抛 "Lookup would require extrapolation into the future"
```

> 实测 API 注意（Humble）：
> - **没有返回 bool 的阻塞版 waitForTransform**（那是 tf2_ros 老接口的假记忆）；
>   要"最多等 N 秒"，用 `canTransform` 轮询（p08 的 tf_listener 就是这么写的）。
> - `tf2::TimePointZero` 转消息时间戳用 **`tf2_ros::toMsg`**（在 buffer_interface.hpp），写 `tf2::toMsg` 编译不过。

## 5. ROS 1 → 2 对照与坑

| ROS 1 | ROS 2 |
|---|---|
| tf / tf2 两套并存 | 只有 tf2 |
| `tf::TransformListener` | `tf2_ros::Buffer` + `tf2_ros::TransformListener` |
| `tf::TransformBroadcaster::sendTransform` | `tf2_ros::TransformBroadcaster` / `StaticTransformBroadcaster` |
| `ros::Time(0)` 表示最新 | `tf2::TimePointZero` |
| **CLI 静态发布器位置参数** | Humble 必须用命名参数：`ros2 run tf2_ros static_transform_publisher --x 1 --y 0 --z 0 --yaw 0 --frame-id map --child-frame-id odom` |
